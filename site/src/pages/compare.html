Methodology

Each category column describes what tools of that kind typically offer out of the box, summarised from the project's competitive analysis (October 2026). It is a generalisation, not a product test. Individual products vary, sometimes a lot, so read a mark as "usually", not "always". "Partial" means the capability is limited, an add-on, or depends on manual discipline (for example, version history without enforced separation of duties).

Procera's marks reflect the main branch: ✓ means built and covered by automated tests, and ○ means planned for the release shown, per the roadmap. Procera is pre-release, and its first packaged release, R1, targets {{ r1_end }}.

Procera supports evidence and audit practices that compliance programmes rely on; it does not make an organisation compliant with any standard by itself, and it holds no certifications.

When something else is the better choice

  • You need complex, system-to-system automation today. Procera's workflow engine is in progress; the designer and forms are planned for R2. A BPM suite or integration platform fits better now.
  • You only need a team wiki. If nobody has to sign off or acknowledge anything, a wiki is simpler.
  • You don't want to run software. Procera is self-hosted. There is no hosted service today.
  • You need e-signatures, cases or SSO this quarter. They are on the roadmap for R3 to R5, not shipped.
