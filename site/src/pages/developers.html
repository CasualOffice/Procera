Try it

Your first request in a minute

Make a token in Procera (account menu › API tokens), pick only what it needs, and call the API. A token acts as you, with just those permissions, and never approves or signs.

curl https://procera.example.com/api/v1/requests?scope=mine \
  -H "Authorization: Bearer $PROCERA_TOKEN"
