Contributing

Contributions are welcome, from people and from AI-assisted workflows, under the same rules:

  • Design first. Behaviour, data, API, security and UX changes update the design documents before or with the code.
  • Tests with every feature: unit, integration against real PostgreSQL, and an end-to-end scenario.
  • Small commits in Conventional Commits style with a DCO sign-off (git commit -s).
  • Honest claims: "supports" or "-ready", never "compliant" or "certified".

Read CONTRIBUTING.md, the binding engineering rules and the Code of Conduct.
